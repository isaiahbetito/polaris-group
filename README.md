# Polaris Group

Marketing site for **Polaris Group** — Italian SME services across formazione (training), finanza non bancaria (invoice trading / non-bank finance) and advisory direzionale.

- **Production:** https://polaris-group-xi.vercel.app
- **Client:** Cesare Trebeschi (Crema, Lombardia)
- **Languages:** Italian (default) / English — toggle in the nav

## How it's built

Plain HTML/CSS/JS — **no build step, no framework**. Pages are static files, served by Vercel as-is.

- `index.html` — home (own inline CSS, transparent-over-hero nav)
- `chi-siamo.html` · `servizi.html` · `contatti.html` · `lavora-con-noi.html` · `casi-testimonianze.html` — inner pages
- `team/cesare-trebeschi.html` — founder profile (hand-built)
- `team/{cristina,alessio,gianmaria,mara,paola,andrea,giovanni}.html` — team profiles (generated by `scripts/gen-team.mjs`)
- `assets/site.css` + `assets/site.js` — shared foundation for inner pages (lang toggle, mobile hamburger, scroll-reveal, count-up)
- `img/` — photos, videos (cinematic backgrounds), fund-body logos
- `favicon-*.png` — navy-star favicon at multiple sizes

## Editing

**Via GitHub web UI** — open any file, click the pencil icon, edit, commit. Pushes to `main` auto-deploy to production within ~30 seconds.

**Bilingual text** uses paired attributes:

```html
<p data-it="Testo italiano" data-en="English text">Testo italiano</p>
```

The visible text and `data-it` should match; `data-en` provides the English variant. For content with inline HTML, use `data-it-html` / `data-en-html` instead.

## Regenerating team pages

After editing `scripts/gen-team.mjs` (member data, expertise cards, etc.):

```bash
node scripts/gen-team.mjs
```

This overwrites the 7 non-founder team pages. The founder page (`team/cesare-trebeschi.html`) is hand-maintained and **not** touched by the generator.

## Local dev

Any static server works:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

Pushes to `main` auto-deploy to production via the GitHub → Vercel integration.

For manual deploys from a local clone:

```bash
vercel --prod --scope isaiah-betitos-projects
```
